# Chat Starter (App 04 patterns)

Runs **without Firebase** using an in-memory mock + auto “friend” echo.

```bash
cd sample-apps/chat_starter
flutter pub get
flutter run
```

## Upgrade path

1. Finish Level 11 Firebase  
2. Follow `Full-App-Tutorials/App-04-Realtime-Chat-Firebase/README.md`  
3. Replace `MockChatRepository` with Firestore streams + rules  
4. Add FCM from Level 21 / App 04 `fcm/` notes
