# Ride Hail Starter (App 05)

Runnable **mock** rider/driver trip state machine.

```bash
cd sample-apps/ride_hail_starter
flutter pub get
flutter run
```

## Flow

1. Open as **Rider** → Request ride  
2. Open as **Driver** (new route) → Accept  
3. Driver advances: Arriving → Start → Complete  
4. Illegal transitions throw and show error  

Maps / live GPS: see `Full-App-Tutorials/App-19-Ride-Map-Tracking-Lab` and App 05 docs.
