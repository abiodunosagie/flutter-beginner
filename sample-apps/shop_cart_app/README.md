# ShopCart sample (Level 06)

Runnable cart app used by the Flutter Beginner course.

```bash
cd sample-apps/shop_cart_app
flutter pub get
flutter run
```

## Learn

- Course walkthrough: `../../Level-06-State-Management/Build-This-App/FULL_WALKTHROUGH.md`
- Provider badge + totals update live across screens

## Test checklist

1. Add two products → badge shows 2  
2. Open cart → change qty → total updates  
3. Clear cart → empty state
