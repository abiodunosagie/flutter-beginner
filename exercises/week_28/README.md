# Week 28: Exercises

## Overview
This week's exercises are based on the lessons in Phase 28/Week 28.

Refer to the corresponding lesson files in:
`lessons/phase_X_topic/week_28_subtopic/`

## Exercise Structure

Each lesson includes 5 progressive exercises:
1. **Beginner**: Basic implementation
2. **Beginner-Intermediate**: Adding features
3. **Intermediate**: Complex scenarios  
4. **Intermediate-Advanced**: Production patterns
5. **Advanced**: Real-world challenges

## Finding Exercises

Exercises are located at the end of each lesson file:
- Open the lesson markdown file
- Scroll to "Exercises" section
- Follow the requirements for each exercise level

## Submitting Solutions

Create your solution files in this directory:
`exercises/week_28/exercise_1.dart`
`exercises/week_28/exercise_2.dart`
etc.

## Getting Help

- Review the lesson content
- Check the code examples in the lesson
- Refer to previous weeks' exercises
- Build progressively from beginner to advanced

Happy coding! 🚀
