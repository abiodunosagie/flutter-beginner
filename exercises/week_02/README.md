# Week 2: Functions Exercises

## Exercise 1: Calculator Functions (Beginner)
Create functions for basic arithmetic operations.

**Requirements:**
- Create `add(a, b)`, `subtract(a, b)`, `multiply(a, b)`, `divide(a, b)`
- Test with different numbers
- Handle division by zero

## Exercise 2: Temperature Converter (Beginner-Intermediate)
Create functions to convert temperatures.

**Requirements:**
- `celsiusToFahrenheit(celsius)`
- `fahrenheitToCelsius(fahrenheit)`
- Named parameters with default values
- Return results with 2 decimal places

## Exercise 3: String Utilities (Intermediate)
Create utility functions for strings.

**Requirements:**
- `reverseString(text)` - reverse a string
- `isPalindrome(text)` - check if palindrome
- `countVowels(text)` - count vowels
- `capitalizeWords(text)` - capitalize first letter of each word

## Exercise 4: List Operations (Intermediate-Advanced)
Create functions that work with lists.

**Requirements:**
- `findMax(numbers)` - find maximum value
- `calculateAverage(numbers)` - calculate average
- `removeDuplicates(items)` - remove duplicates
- `sortDescending(numbers)` - sort in descending order

## Exercise 5: Password Validator (Advanced)
Create a password validation function.

**Requirements:**
- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character
- Return detailed validation message
