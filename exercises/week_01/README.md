# Week 1 Exercises

Complete these exercises after finishing Week 1 lessons.

---

## Exercise 1: Hello World Variations

**Difficulty:** ⭐ Beginner

**Goal:** Practice using print() and basic syntax

**Tasks:**
1. Print "Hello, World!" to the console
2. Print your name on a separate line
3. Print the current year
4. Print a fun fact about yourself

**Expected Output:**
```
Hello, World!
John Doe
2024
I love coding!
```

**Hints:**
- Each print() statement goes on a new line
- Don't forget semicolons!

---

## Exercise 2: Personal Info Card

**Difficulty:** ⭐⭐ Easy

**Goal:** Create variables for personal information

**Tasks:**
1. Create variables for:
   - First name (String)
   - Last name (String)
   - Age (int)
   - Height in feet (double)
   - Are you a student? (bool)

2. Print them in a formatted way

**Expected Output:**
```
===== PERSONAL INFO =====
Name: John Doe
Age: 25
Height: 5.9 ft
Student: true
```

**Hints:**
- Use String interpolation: `'Name: $firstName $lastName'`
- Combine first and last name

---

## Exercise 3: Simple Calculator

**Difficulty:** ⭐⭐ Easy

**Goal:** Practice arithmetic operations

**Tasks:**
1. Create two number variables (a = 15, b = 4)
2. Calculate and print:
   - Sum (a + b)
   - Difference (a - b)
   - Product (a * b)
   - Quotient (a / b)
   - Remainder (a % b)

**Expected Output:**
```
a = 15, b = 4
Sum: 19
Difference: 11
Product: 60
Quotient: 3.75
Remainder: 3
```

---

## Exercise 4: Temperature Converter

**Difficulty:** ⭐⭐ Medium

**Goal:** Use variables and calculations

**Tasks:**
1. Create a variable for temperature in Celsius (e.g., 25)
2. Convert to Fahrenheit using formula: F = (C × 9/5) + 32
3. Print both temperatures

**Expected Output:**
```
25°C = 77°F
```

**Hints:**
- Use double for decimal precision
- Formula: `fahrenheit = (celsius * 9 / 5) + 32`

---

## Exercise 5: Price Calculator

**Difficulty:** ⭐⭐ Medium

**Goal:** Calculate total price with tax

**Tasks:**
1. Create variables:
   - Product price: $49.99
   - Tax rate: 8% (0.08)
2. Calculate:
   - Tax amount
   - Total price (price + tax)
3. Print itemized breakdown

**Expected Output:**
```
Product Price: $49.99
Tax (8%): $4.00
Total: $53.99
```

**Hints:**
- Tax = price × taxRate
- Total = price + tax
- Use `toStringAsFixed(2)` for 2 decimal places (preview of methods you'll learn)

## Exercise 6: Age Calculator

**Difficulty:** ⭐⭐⭐ Medium

**Goal:** Multiple calculations from one input

**Tasks:**
1. Create variable for age in years (e.g., 25)

## Exercise 8: BMI Calculator

**Difficulty:** ⭐⭐⭐ Hard

**Goal:** Real-world calculation

**Tasks:**
1. Create variables:
   - Weight in kilograms (e.g., 70)
   - Height in meters (e.g., 1.75)
2. Calculate BMI: weight / (height × height)
3. Print weight, height, and BMI

**Expected Output:**
```
Weight: 70 kg
Height: 1.75 m
BMI: 22.9
```

**Bonus:** Print BMI with only 1 decimal place

---

## Exercise 9: Shopping Cart Total

**Difficulty:** ⭐⭐⭐ Hard

**Goal:** Multiple items and totals

**Tasks:**
1. Create variables for 3 products:
   - Item 1: Name, price, quantity
   - Item 2: Name, price, quantity
   - Item 3: Name, price, quantity
2. Calculate:
   - Subtotal for each item (price × quantity)
   - Total of all items
3. Print itemized list and total

**Expected Output:**
```
SHOPPING CART
-------------
Laptop    x1  = $999.00
Mouse     x2  = $50.00
Keyboard  x1  = $75.00
-------------
TOTAL: $1124.00
```

## Exercise 10: Final Challenge - Complete Portfolio

**Difficulty:** ⭐⭐⭐⭐ Hard

**Goal:** Combine everything from Week 1

**Tasks:**
Create the most impressive portfolio/bio you can with:
1. Personal information (name, age, location, etc.)
2. Professional info (student/job, experience)
3. Skills (at least 3)
4. Contact info (email, website, social media)
5. Statistics (age in different units, projects completed, etc.)
6. Beautiful formatting with borders, emojis, symbols
7. At least 5 calculated values (age in months, etc.)

This should be your masterpiece! Make it impressive!
