# Week 5: OOP Advanced - Inheritance & Polymorphism

## Exercise 1: Animal Hierarchy (Beginner)
Create animal class hierarchy.

**Requirements:**
- Base Animal class
- Dog, Cat, Bird subclasses
- Override makeSound() method
- Specific properties for each animal

## Exercise 2: Employee System (Beginner-Intermediate)
Employee types with inheritance.

**Requirements:**
- Base Employee class
- FullTimeEmployee, PartTimeEmployee, Contractor
- Different salary calculations
- Benefits for full-time only

## Exercise 3: Shape Calculator (Intermediate)
Polymorphic shape calculations.

**Requirements:**
- Abstract Shape class
- Circle, Rectangle, Triangle subclasses
- area() and perimeter() methods
- List of mixed shapes
- Calculate total area

## Exercise 4: Vehicle Management (Intermediate-Advanced)
Vehicle rental system.

**Requirements:**
- Vehicle base class
- Car, Motorcycle, Truck subclasses
- Calculate rental price (different formulas)
- Maintenance schedules
- Polymorphic list operations

## Exercise 5: Payment Processing (Advanced)
Payment system with multiple payment types.

**Requirements:**
- Abstract Payment class
- CreditCard, PayPal, BankTransfer subclasses
- process() method with different logic
- Transaction fees (different per type)
- Refund handling
- Payment history
