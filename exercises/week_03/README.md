# Week 3: Collections Exercises

## Exercise 1: Shopping List (Beginner)
Create and manipulate a shopping list using Lists.

**Requirements:**
- Add items to list
- Remove items from list
- Check if item exists
- Display all items
- Count total items

## Exercise 2: Student Grades (Beginner-Intermediate)
Use Map to store student names and grades.

**Requirements:**
- Add students with grades
- Update grades
- Calculate class average
- Find highest grade
- List all students

## Exercise 3: Unique Items (Intermediate)
Use Set to handle unique items.

**Requirements:**
- Add items to set
- Check for duplicates
- Perform set operations (union, intersection, difference)
- Convert between List and Set

## Exercise 4: Inventory System (Intermediate-Advanced)
Create inventory using Map of Lists.

**Requirements:**
- Store products with quantities
- Add/remove products
- Update quantities
- Calculate total inventory value
- Low stock alerts

## Exercise 5: Contact Manager (Advanced)
Complex nested collections.

**Requirements:**
- Store contacts with multiple phone numbers
- Email addresses in Set (unique)
- Tags/categories for each contact
- Search by name, phone, or email
- Group contacts by category
