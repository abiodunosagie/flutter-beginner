# Week 4: OOP Basics Exercises

## Exercise 1: Person Class (Beginner)
Create a Person class with properties and methods.

**Requirements:**
- Properties: name, age, email
- Constructor
- `introduce()` method
- Getters and setters
- Age validation (must be > 0)

## Exercise 2: Bank Account (Beginner-Intermediate)
Create BankAccount class.

**Requirements:**
- Properties: accountNumber, balance, ownerName
- Methods: deposit(), withdraw(), getBalance()
- Prevent negative balance
- Transaction history

## Exercise 3: Rectangle Class (Intermediate)
Create geometry classes.

**Requirements:**
- Properties: width, height
- Methods: area(), perimeter()
- Named constructors (square)
- Validation (positive dimensions)

## Exercise 4: Product Inventory (Intermediate-Advanced)
Create Product and Inventory classes.

**Requirements:**
- Product: name, price, quantity, SKU
- Inventory: list of products
- Add/remove products
- Calculate total value
- Search by name or SKU

## Exercise 5: Library System (Advanced)
Complete library management.

**Requirements:**
- Book class (title, author, ISBN, available)
- Member class (name, memberID, borrowedBooks)
- Library class (books, members)
- Borrow/return functionality
- Due dates and fines
