# Level 1: Real-World Apps Using These Concepts

See how the fundamentals you're learning power real applications!

---

## Variables & Data Types

### Every App Uses Variables!

**Instagram**
- `String username` - Your profile name
- `int followerCount` - Number of followers
- `bool isVerified` - Blue checkmark status

**Uber**
- `double tripCost` - Fare for your ride
- `String driverName` - Your driver's name
- `int estimatedMinutes` - Arrival time

**Spotify**
- `String songTitle` - Currently playing song
- `int playCount` - How many times a song was played
- `bool isPremium` - Subscription status

## Strings

### Text is Everywhere!

**WhatsApp**
```dart
String message = 'Hello! How are you?';
String formattedTime = '2:30 PM';
String contactName = 'Mom';
```

**Twitter/X**
```dart
String tweet = 'Just shipped a new feature! #Flutter';
int characterCount = tweet.length;  // 280 character limit!
```

**Google Maps**
```dart
String address = '1600 Amphitheatre Parkway';
String directions = 'Turn left in 500 meters';
```

---

## Numbers

### Math Powers Everything!

**Banking Apps (PayPal, Venmo)**
```dart
double balance = 1250.50;
double transferAmount = 100.00;
double newBalance = balance - transferAmount;
```

**Fitness Apps (Strava, Nike Run)**
```dart
double distanceKm = 5.2;
int caloriesBurned = 320;
double averagePace = 6.5;  // minutes per km
```

**E-commerce (Amazon, eBay)**
```dart
double itemPrice = 29.99;
double taxRate = 0.08;
double totalPrice = itemPrice * (1 + taxRate);
```

## Booleans

### Yes/No Decisions Everywhere!

**Netflix**
```dart
bool hasActiveSubscription = true;
bool isDownloaded = false;
bool isWatching = true;
```

**Instagram**
```dart
bool isPrivateAccount = false;
bool isFollowing = true;
bool hasNotificationsOn = true;
```

**Slack**
```dart
bool isOnline = true;
bool doNotDisturb = false;
bool hasUnreadMessages = true;
```
