# App 14: Doctor Appointment Booking — Full Tutorial

> Healthtech classic: find doctor, slots, book, my appointments.

**Min level:** 07–11 · **Time:** 14–22 hours  

## Features
- Doctor list by specialty  
- Doctor profile  
- Slot picker (mock next 7 days × times)  
- Booking confirmation  
- Appointments list (upcoming/past)  
- Cancel booking  

## Domain rules
- Cannot double-book same slot  
- Cancel only if >12h away (configurable)  

## Backend
Start mock; upgrade Firestore `doctors`, `slots`, `bookings` with rules.
