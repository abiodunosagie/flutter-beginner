## How to use

1. Finish the **minimum level** for the app.  
2. Prefer `flutter create your_app` and follow the tutorial — **or** start from a sample-app and extend it.  
3. Tick every MVP checkbox before stretch goals.  
4. Ship to GitHub with screenshots.

**Rule:** Finish 5–8 apps deeply rather than skimming all 23.

## Portfolio path (recommended)

```
ShopCart sample → Habit → Movies
  → Chat (+ FCM when L21)
  → Ride hail sample → Map lab (19)
  → Ecommerce or Food
  → Marketplace + payments (L22)
  → one stretch: Music | WebSocket | SaaS | WebRTC
```
