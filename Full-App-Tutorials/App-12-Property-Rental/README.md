# App 12: Property Rental (Airbnb-lite) — Full Tutorial

> Listings map/list, detail, booking date range UI.

**Min level:** 07–12 · **Time:** 16–24 hours  

## Features
- List + map toggle  
- Filters: price range, bedrooms  
- Detail: photos PageView, amenities  
- Booking sheet: check-in/out, guest count, total  
- Wishlist  
- Host profile mock  

## Map
Markers from listing lat/lng; select marker → bottom sheet.

## Pricing
`nights * pricePerNight + cleaningFee`

## Portfolio
> Property rental explorer with map/list modes and booking price breakdown.
