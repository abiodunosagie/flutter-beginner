# Firebase vs Supabase (Decision Guide)

| Need | Prefer |
|------|--------|
| Document-shaped social feed, mature Google SDKs | Firebase |
| SQL, joins, teams, clear RLS | Supabase |
| Heavy Google ecosystem (FCM polish, etc.) | Firebase |
| Portable SQL export | Supabase |

**Skills transfer:** auth sessions, repositories, security on server, streams.
