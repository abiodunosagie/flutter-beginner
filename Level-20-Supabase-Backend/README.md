# Level 20: Supabase Backend for Flutter

> Firebase is not the only backend. **Supabase** = Postgres + Auth + Storage + Realtime with **Row Level Security**.

**Time:** 10–14 hours  
**Prereqs:** Levels 08, 11 concepts (auth + remote data)

## Learning path

1. Theory in order  
2. Examples  
3. Exercises  
4. **Build-This-App** cloud todos with RLS  

## Why this level exists

Many companies use Supabase, Appwrite, or custom Postgres. You should not only know Firebase.
