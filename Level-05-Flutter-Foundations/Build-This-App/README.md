# Build This App — Profile & Business Card App

> **Level app project** (not a toy snippet). Complete this after the level theory/exercises.

**Time:** 4–6 hours  
**Why it matters:** Prove you can compose real UI without state libraries.

---

## Product

You are building: **Profile & Business Card App**

## Acceptance checklist

- [ ] Profile header with avatar placeholder and name/title
- [ ] Contact rows (email, phone, location) with icons
- [ ] Skills chips Wrap
- [ ] Social buttons row
- [ ] Dark/light friendly colors using Theme
- [ ] Extract widgets: ProfileHeader, InfoTile, SkillChip

## Steps

1. flutter create profile_card_app && open in IDE
2. Build with MaterialApp + ThemeData
3. Replace home with ProfilePage scaffold
4. Extract private widgets into widgets/ folder
5. Add second page About via simple Navigator.push (preview of L07)

## Definition of done

Screenshot profile on phone + tablet width
