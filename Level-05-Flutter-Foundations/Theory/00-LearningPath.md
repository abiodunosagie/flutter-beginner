# Level 5: Flutter Foundations - Learning Path

Welcome to Level 5! This is where you start building actual Flutter apps! This level teaches you the fundamental building blocks of Flutter.

---

## How to Use These Theory Files

Read these theory files **in order**, one at a time. Each file teaches you ONE Flutter concept.

After each theory file, practice with the matching PART exercises to build real widgets!

## Total Time for Level 5 Theory

**Estimated:** 4 - 4.5 hours (including practice)

This is a big level - you're learning to build real UIs!

---

## Learning Strategy

1. **Read one theory file**
2. **Create the widgets in the exercises**
3. **Run the app and see your widgets live!**
4. **Experiment with different properties**
5. **Move to next concept**

**Visual learning is key** - see your widgets on screen!

---

## After Completing Level 5

Once you've finished all theory and exercises:

1. **Review the concepts:**
   - Can you create both stateless and stateful widgets?
   - Do you understand layouts with Row, Column, Stack?
   - Can you build scrollable lists?

2. **Complete the Final Project:**
   - Build a complete UI using all widgets learned

3. **Self-Assessment Checklist**

---

## Learning Tips

✅ **DO:**
- Use hot reload constantly to see changes
- Experiment with widget properties
- Build the examples yourself (don't just read!)
- Use Flutter DevTools to inspect widget tree

❌ **DON'T:**
- Skip running the code on a real device/emulator
- Just copy-paste without understanding
- Rush through layouts (they're fundamental!)
- Move to Level 6 without understanding state
