## Quick Reference: When to Use What

### Navigation
- **Simple navigation**: Navigator.push
- **Complex apps**: GoRouter
- **Deep linking needed**: GoRouter
- **Nested navigation**: GoRouter with ShellRoute

### Backend
- **Need auth + database**: Firebase
- **Real-time features**: Firestore real-time listeners
- **File storage**: Firebase Storage
- **Backend logic**: Cloud Functions

### State Management
- **Simple state**: setState or Provider
- **Medium complexity**: Riverpod
- **Complex business logic**: BLoC
- **Real-time data**: StreamProvider

### Performance
- **Slow rebuilds**: Use const, keys, RepaintBoundary
- **Memory issues**: DevTools memory profiler
- **Large lists**: ListView.builder with lazy loading
- **Heavy computations**: Isolates or compute()
