# How to Learn This Course (Read Once)

This course is built so you **do not need to invent the path**. Follow this loop for every level.

## The loop

```
1. Level README          → what you'll learn
2. Theory/ files         → in order
3. Examples/             → run or type them
4. Exercises/            → struggle productively
5. Build-This-App/       → required mini product
6. Checkpoint (if any)   → self-test
7. Next level
```

## When to open Full-App-Tutorials

| Your situation | Do this |
|----------------|---------|
| Still on Levels 1–5 | Stay on Build-This-App only |
| Finished Level 6 cart | Optional: Habit or Expense full app |
| Finished Level 8 | Movie Browser full app |
| Finished Level 11 | **Realtime Chat** full app |
| Want a standout portfolio | **Ride Hailing** + one of Chat / Marketplace / Delivery |

## Quality bar for “I’m done”

- App runs from cold start  
- Empty + loading + error states exist where network/storage is used  
- You can explain the folder structure in 60 seconds  
- No API secrets in git  

## If you feel lost

1. Re-read the level’s **Build-This-App** acceptance checklist  
2. Compare to `Full-App-Tutorials/TUTORIAL_STANDARD.md`  
3. Shrink scope: ship MVP checkboxes before stretch goals  

## Do not

- Skip Build-This-App and only read theory  
- Copy-paste without typing (you will not remember)  
- Start Ride Hailing before navigation + state feel easy
