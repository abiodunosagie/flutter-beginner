## 💡 Interview Tips

### During Coding Questions

1. **Clarify Requirements**
   - Ask questions before coding
   - Confirm expected behavior
   - Discuss edge cases

2. **Think Out Loud**
   - Explain your approach
   - Talk through trade-offs
   - Mention alternatives

3. **Write Clean Code**
   - Proper naming
   - Comments where needed
   - Follow conventions

4. **Test Your Code**
   - Walk through examples
   - Consider edge cases
   - Fix bugs you find

### During Conceptual Questions

1. **Start Simple**
   - Give basic explanation first
   - Then add details
   - Use examples

2. **Use Visuals**
   - Draw diagrams if possible
   - Use analogies
   - Show code examples

3. **Be Honest**
   - If you don't know, say so
   - Explain how you'd find out
   - Show willingness to learn
