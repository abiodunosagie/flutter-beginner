# Build This App — Interview Demo Pack

> Not a new product: package **one** existing app as a live interview demo.

**Time:** 4–8 hours  
**Why it matters:** Interviews reward clarity under questions, not 20 half-repos.

## Choose one demo app

Pick **one**:

1. Level 06 ShopCart  
2. Full-App Realtime Chat  
3. Full-App Ride Hailing (state machine talk track)  

## Acceptance checklist

- [ ] 90-second spoken walkthrough script written  
- [ ] Architecture diagram (boxes) in README  
- [ ] Three hard questions answered in `INTERVIEW_NOTES.md`:  
  - How does state update the badge / stream?  
  - What breaks if rules/lifecycle are wrong?  
  - How would you scale this?  
- [ ] `flutter analyze` clean on demo app  
- [ ] Known issues listed honestly  

## Steps

1. Polish the chosen app (empty/error states).  
2. Write `INTERVIEW_NOTES.md` in that repo.  
3. Practice aloud once.  
4. Optional: record Loom.

## Definition of done

You can demo without reading code line-by-line, and defend architecture choices.
