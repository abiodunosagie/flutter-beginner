## Learning Tips

✅ **DO:**
- Start with implicit animations
- Use curves for natural motion
- Keep animations subtle
- Test on real devices
- Follow Material Design guidelines
- **Use flutter_animate for quick declarative animations**
- **Use Lottie for designer-created animations**
- **Use Rive for interactive, state-driven animations**
- **Download animations from LottieFiles**

❌ **DON'T:**
- Over-animate everything
- Use animations that slow down UX
- Ignore animation performance
- Make animations too long
- Forget to dispose controllers
- **Use heavy animation packages for simple effects**
- **Ignore file sizes of Lottie/Rive animations**
- **Forget to test animations on lower-end devices**
