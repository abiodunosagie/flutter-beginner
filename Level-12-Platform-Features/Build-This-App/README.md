> **Level app project** (not a toy snippet). Complete this after the level theory/exercises.

## Product

You are building: **Map Check-In Journal**

## Acceptance checklist

- [ ] Show user location on map
- [ ] Button to check-in current place
- [ ] Optional photo via image_picker
- [ ] List of check-ins with lat/lng
- [ ] Permission denied UX

## Steps

1. Add geolocator, google_maps_flutter, image_picker
2. Configure API keys safely
3. Implement permission flow
4. Persist check-ins locally

## Definition of done
