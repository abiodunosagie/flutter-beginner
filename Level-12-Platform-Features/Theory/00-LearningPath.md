## Learning Strategy

1. **Read one theory file**
2. **Implement the feature**
3. **Test on real device** (some features don't work on simulator!)
4. **Handle permissions properly**
5. **Move to next feature**

## Learning Tips

✅ **DO:**
- Test on real devices
- Handle permission denials gracefully
- Check permission status before using
- Update AndroidManifest.xml and Info.plist
- Provide clear permission rationale

❌ **DON'T:**
- Assume permissions are granted
- Test only on emulator
- Forget to request permissions
- Ignore platform-specific setup
- Request unnecessary permissions
