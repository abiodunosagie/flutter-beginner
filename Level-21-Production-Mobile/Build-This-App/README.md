# Build This App — Production Hardening Lab

Pick **one** existing app (Chat starter or ShopCart).

## Checklist

- [ ] Document ENV dart-defines for dev vs prod URLs  
- [ ] Add GitHub Actions workflow (analyze + test)  
- [ ] (Firebase apps) enable Crashlytics smoke test  
- [ ] (Chat) design token collection schema for FCM  
- [ ] Privacy note: what analytics you would log  

## Done when

CI is green on GitHub and you can explain the FCM token lifecycle in 2 minutes.
